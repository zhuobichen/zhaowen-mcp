# weather-mcp

逐小时天气预报，**为出行/骑行决策服务**：查某地某天的降水、温度、风，并直接给出「什么时候不下雨」。

数据源 **Open-Meteo**（免费、无需 API key、无需注册）。

> 为什么不复用已有的 `amap-maps.maps_weather`：**它只给到「白天/夜间」两级**。
> 而"该几点出发"这种问题，靠白天/夜间是答不出来的——本服务就是补这个粒度。

## 工具

| 工具 | 作用 |
| --- | --- |
| `hourly_forecast` | 逐小时预报：气温、降水量、降水概率、天气、风向风速。可按日期/小时过滤 |
| `dry_windows` | **找某天连续无雨的时间窗**——直接回答「几点到几点不下雨」 |
| `resolve_place` | 地名 → 经纬度（上面两个工具直接用中文地名也行） |

## 「无雨窗口」的判据（这是设计的核心）

判据是**两个条件同时满足**：

```
降水 ≤ mm_tol  且  降水概率 ≤ prob_tol
```

**为什么不能只看降水量**：只看 mm 会把「降水概率 85%、但这一小时恰好只下了 0.1mm」当成好天气。
概率高意味着**随时可能下**，对"该不该出门"是误导。

**阈值都可调**，因为「怕不怕雨」因人而异：

| 场景 | 建议参数 |
| --- | --- |
| 怕淋雨（默认） | `prob_tol=50` |
| **不在意小雨**（骑车、短途） | `prob_tol=90` ← 更贴合实际 |
| 只避雷阵雨/大雨 | `mm_tol=2.5`、`prob_tol=90` |
| 全程要干 | `prob_tol=20` |

⚠️ **默认值（`prob_tol=50`）假设用户怕雨。** 如果你不在意淋一点，一定要把它调高，
否则「概率 85% 的小毛毛雨」会被全部刷掉——**而那可能正是你能用的时段**。

## ⚠️ 别自己再做时区换算

返回的 `time` 字段**已经是 `Asia/Shanghai` 本地时间**（形如 `2026-10-05T07:00`），
请求时已带 `timezone=Asia/Shanghai`。**再减一次 8 小时就错了。**

（这是本仓库踩过的同类坑：时间戳换算是静默出错重灾区，改一次错一次，症状都是"数据变少"。）

## 已知限制

- **预报可靠度随天数递减。** 3 天以内可用；**4 天以上的数字会变**，别把行程钉死在远期预报上。
- **中文地名命中率有限。** Open-Meteo 的地理库对中文支持一般，查不到时改用 `"纬度,经度"`。
- **风向要自己判断顺逆。** 工具只报风向（如「北风」），不会替你判断"往北骑是不是逆风"——
  **那是路线的事，它不知道你要去哪。**
- **不提供历史天气**，只看未来（上限 16 天）。

## 开发

```bash
npm install
npm run typecheck
npm test          # selftest.mjs：真走 stdio JSON-RPC，含筛选器判别力测试
```

selftest 特意做了**判别力**断言：宽阈值找到的窗口数必须 **≥** 默认 **≥** 严阈值。
只断言「有返回」是恒真的，测不出筛选器坏没坏。
