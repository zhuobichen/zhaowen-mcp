# 场景 2：发票自动入库

覆盖四种场景：出差期间每日扫、出差回来一次性入库、每月批量入库、临时手动传。

## 通用处理流程

所有场景共享同一套处理骨架。

### 目录约定

- 出差：`d:\报销\<批次名>\`（如 `d:\报销\2026-08-云浮出差\`）
- 月度：`d:\报销\<YYYY-MM>\`
- 临时：`d:\Desktop\发票待填报\`

### 逐文件处理

1. 列出目录下所有 `*.pdf` / `*.jpg` / `*.png` / `*.ofd`。
2. 每个文件：
   - CLI `upload` → 拿文件 ID。
   - CLI `parse` → 拿发票字段。
   - 解析失败（OFD、加密 PDF、扫描件识别不出金额）→ 跳过，记入"待人工处理"。
   - 解析成功 → `create_invoice_invoice_create_post`，`status=0`，关联文件 ID，按归属策略匹配项目。
   - 识别为行程单/收据（不是发票金额）→ 只在已确认关联发票时 CLI `add-attachment` 绑定。不确定的记入"待人工处理"，别自动建 0 元发票。
3. 处理完输出汇总（按项目分组），成功清单 + 待处理清单都记下来。

## 项目归属策略

| 场景 | 怎么归 | 问不问 |
|------|--------|--------|
| 出差 | 整批挂一个项目，首次确认 | 开批次时问一次，后续不问 |
| 月度 | 按用户预设的关键字/目录规则匹配，不准按购方名称推断 | 没命中记待处理，不逐张问 |
| 临时 | 挂默认项目，可在对话里调 | 每张展示摘要给你看 |

## 四种 automation

### (a) 出差期间每日扫

- 每天 21:00 扫出差目录，处理新增文件。
- `scheduleType=recurring`，`rrule=FREQ=DAILY;BYHOUR=21;BYMINUTE=0`
- `validFrom=出差开始`，`validUntil=出差结束+1天`
- `prompt`：扫目录，按出差归属策略入库。别动用户文件（不移动不重命名）。

### (b) 出差回来一次性入库

- 回程当晚一次性扫整个出差目录。
- `scheduleType=once`，`scheduledAt=回程当日 21:00`
- `prompt`：扫目录全量入库，生成汇总。

### (c) 月度入库

- 每月 1 日 09:00 扫上月目录。
- `scheduleType=recurring`，`rrule=FREQ=MONTHLY;BYMONTHDAY=1;BYHOUR=9;BYMINUTE=0`
- `prompt`：扫上月目录，按月度归属策略匹配项目，生成汇总。

### (d) 临时手动

- 不建 automation，对话里直接说就行。
