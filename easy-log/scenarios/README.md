## 通用约定

- 只暂存不提交，最终审核在网站完成。
- automation 的 `prompt` 里写清"不要问用户"还是"只在必要时问"。
- 失败的条目记"待人工处理"，不中断整体流程。

## 怎么启用

告诉我"启用场景 X，项目=xxx，文件夹=xxx，工时=N"，我来建 automation。也可以先说"dry-run 跑一遍看看效果"。
